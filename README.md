# Grid Dewa (APK)

1. Upload semua isi folder ini ke repo GitHub (branch main).
2. Buka tab Actions, tunggu "Build APK" selesai (sekitar 5-10 menit).
3. Buka run yang berhasil, bagian Artifacts, unduh GridDewa-APK.
4. Ekstrak zip, pasang app-debug.apk di HP (izinkan "Install dari sumber tidak dikenal").

Mengubah aplikasi: edit www/index.html lalu commit, APK dibangun ulang otomatis.
